# КОМПАНЬОН / SHIBA 01

[Открыть 3D-сайт](https://step3dlab.github.io/vr_anapa/kompanion-case/)

Чехол с настоящей гравировкой сиба-ину. Вращение, приближение, виды снаружи и изнутри, выбор цвета. Есть облегчённый 3D-режим без WebGL.

## Для печати

В `downloads/`: STL, STEP для iPhone 18 Pro и Pro Max, пробники посадки, комплект ZIP, рисунок SVG, инструкция и отчёт геометрии.

**Это прототип, физическая посадка не проверена.** Уточните модель телефона и сначала напечатайте пробник. Материал — TPU 95A. Модель без магнитов MagSafe и выступа над линзами.

## Исходники

Сайт не требует сборки: `index.html`, `style.css`, `app.js`, `software-renderer.js`, `assets/`, `vendor/`. Запуск локально: `python -m http.server 8000` из этой папки.

`python scripts/generate.py` восстанавливает геометрию в `dist/`; зависимости: cadquery, numpy, shapely, svgpathtools, trimesh, mapbox-earcut, fast-simplification. Геометрия в миллиметрах, масштаб печати 100%.

Проверено: одно валидное CAD-тело; замкнутая связная STL-сетка и согласованные нормали. Источники размеров и ограничения находятся в `downloads/README-RU.txt`.

Three.js и Manrope включены со своими лицензиями. Иллюстрация собаки оригинальная.
