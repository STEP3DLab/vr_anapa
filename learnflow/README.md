# LearnFlow

**LearnFlow** — экспериментальный веб‑продукт в формате «лента коротких знаний»: пользователь свайпает микро‑карточки, а система адаптирует рекомендации по интересам и поведению.

## Live
https://step3dlab.github.io/vr_anapa/learnflow/

## Что реализовано
- полноэкранная вертикальная лента;
- onboarding по интересам и глубине объяснений;
- режимы «Для вас» и «Исследовать»;
- лайк, сохранение, «уже знал» и «не интересно»;
- адаптивный вес тем по действиям пользователя;
- около 20% рекомендаций вне выбранных тем для расширения кругозора;
- многоуровневая карточка: тезис → объяснение → запоминание → источник;
- мини‑тесты для активного воспроизведения;
- очередь повторения;
- локальная статистика прогресса;
- сохранение состояния в localStorage;
- мобильная и desktop‑версия.

## Продуктовый принцип
Не максимизировать бесконечный просмотр сам по себе, а превращать короткую сессию в измеримое обучение: заинтересовать → объяснить → попросить воспроизвести → повторить позже.

Текущая версия — front-end MVP без серверной авторизации и общей облачной базы данных.
