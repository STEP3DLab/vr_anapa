# LearnFlow

**LearnFlow** — персональная лента коротких знаний: формат быстрого вертикального контента, но с образовательным циклом **заинтересовать → объяснить → вспомнить → повторить**.

## Live
https://step3dlab.github.io/vr_anapa/learnflow/

## Версия v3

### Лента и персонализация
- режимы **Для вас**, **Открытия**, **Быстрый тест**;
- выбор интересов и глубины объяснений;
- рекомендации учитывают лайки, сохранения, раскрытие объяснений, отметку «уже знаю», время просмотра и быстрые пропуски;
- около 20% выдачи намеренно расширяет кругозор за пределами выбранных тем;
- объяснение «почему эта карточка показана».

### Обучение
- многоуровневая карточка: hook → короткое объяснение → механизм → memory hook → источник;
- вопросы на активное воспроизведение;
- интервальное повторение по каждой изученной карточке;
- оценки **Не помню / Трудно / Помню** изменяют срок следующего повторения;
- режим отдельной тренировки памяти.

### Привычка и прогресс
- дневная цель 3–30 знаний;
- серия активных дней;
- экран достижения дневной цели;
- статистика изученного и точности;
- визуальный профиль интересов;
- сохранённая библиотека;
- экспорт локального прогресса в JSON.

### Приложение
- mobile-first интерфейс;
- deep-link на отдельный факт: `#fact=<id>`;
- Web Share / копирование ссылки;
- PWA manifest;
- service worker и офлайн-кэш;
- установка на поддерживаемых устройствах;
- миграция локального прогресса из предыдущей версии.

## Структура
- `index.html` — точка входа;
- `styles.css` — интерфейс;
- `app.js` — данные, рекомендации, обучение и состояние;
- `manifest.webmanifest` — PWA;
- `sw.js` — offline cache;
- `icon.svg` — иконка.

## Следующий production-этап
Текущая версия остаётся статическим front-end MVP. Для production нужны:
1. авторизация и синхронизация прогресса;
2. серверная БД знаний и CMS редактора;
3. валидация источников и редакционный workflow;
4. серверный рекомендательный сервис;
5. семантический граф тем и знаний;
6. продуктовая аналитика с приватностью по умолчанию.
