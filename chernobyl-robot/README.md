# Мобот-Ч-ХВ-2 · WebXR

Интерактивная музейная 3D-сцена для ПК и Meta Quest, собранная по архивным фотографиям, материалам СКТБ прикладной робототехники и рабочей научной редакции проекта «Роботы Чернобыля».

## Публичные адреса

- Полная версия: https://step3dlab.github.io/vr_anapa/chernobyl-robot/
- Версия для iframe: https://step3dlab.github.io/vr_anapa/chernobyl-robot/embed.html
- Компактный режим: https://step3dlab.github.io/vr_anapa/chernobyl-robot/?embed=1

## Что появилось в текущей версии

- WebXR для Meta Quest и свободный просмотр на ПК.
- 8 интерактивных технических узлов с пояснениями.
- Исправлено прежнее ошибочное обозначение «гидропривод»: в описании комплекса приводы рассматриваются как электромеханические.
- Режим «Пара 1987» — экспозиционная компоновка двух модернизированных комплексов.
- Условный вид бортовой телекамеры.
- Отдельные режимы «Инженерный» и «Экспозиционный».
- Схематично добавлены две телекамеры, кабелеукладчик, элементы стыковочного устройства, широкая лопата фронтального погрузчика и детали стрелы.
- Для VR отключаются тяжёлые элементы визуализации, чтобы снизить нагрузку на Quest.

## Управление

ПК: мышь — вращение, колесо — масштаб.

Горячие клавиши:
- `R` — сброс вида;
- `M` — метки;
- `I` — инженерный режим;
- `P` — два комплекса;
- `O` — вид камеры;
- `F` — полный экран.

Meta Quest: нажать «ВОЙТИ В VR»; левый стик — движение, grip — телепорт.

Для входа в immersive VR надёжнее также дать отдельную кнопку, открывающую полную страницу сцены в Meta Quest Browser.

## Точность реконструкции

Сцена не является паспортной CAD-моделью. Открытые узлы и общая компоновка сверяются по архивным ракурсам, но закрытые части, точные размеры и часть геометрии восстановлены приближённо. Цвет также не трактуется как исторически подтверждённый: рабочий фотоархив содержит цветовые реконструкции.
