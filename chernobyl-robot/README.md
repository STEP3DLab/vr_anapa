# Мобот-Ч-ХВ-2 · WebXR

Интерактивная музейная 3D-сцена для ПК и Meta Quest.

## Публичные адреса

- Полная версия: https://step3dlab.github.io/vr_anapa/chernobyl-robot/
- Версия для iframe: https://step3dlab.github.io/vr_anapa/chernobyl-robot/embed.html
- Компактный режим: https://step3dlab.github.io/vr_anapa/chernobyl-robot/?embed=1

## Вставка на сайт

```html
<iframe
  src="https://step3dlab.github.io/vr_anapa/chernobyl-robot/?embed=1"
  title="Мобот-Ч-ХВ-2 — 3D / VR"
  allow="xr-spatial-tracking; fullscreen; autoplay"
  allowfullscreen
  style="width:100%;height:720px;border:0;border-radius:16px">
</iframe>
```

## Управление

ПК: мышь — вращение, колесо — масштаб.  
Meta Quest: кнопка «ВОЙТИ В VR», левый стик — движение, grip — телепорт.

Геометрия реконструкции носит демонстрационный характер и не является точной CAD-моделью.
