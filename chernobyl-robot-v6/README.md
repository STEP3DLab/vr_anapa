# Мобот-Ч-ХВ-2 · WebXR v6

Новая версия цифровой музейной реконструкции для ПК и Meta Quest.

- Полная версия: https://step3dlab.github.io/vr_anapa/chernobyl-robot-v6/

## Новое в v6

- инженерная экскурсия по 9 ключевым узлам;
- уровни уверенности A/B/C для технических карточек;
- отдельный дозиметрический блок ИМД-21Б;
- уточнён двупалый захват;
- исправлено технически неверное обозначение гидропривода;
- сохранены режимы «Пара 1987», «Вид камеры», инженерный и экспозиционный режимы;
- улучшена научная маркировка: подтверждённая функция отделена от условной формы реконструкции.

## Горячие клавиши

R — сброс; M — метки; I — инженерный режим; T — экскурсия; P — пара 1987; O — вид камеры; F — полный экран.

Сцена остаётся исследовательской реконструкцией, а не паспортной CAD-моделью.
