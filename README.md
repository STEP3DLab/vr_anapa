# vr_anapa

## МОБОТ — инженерная реконструкция машин Чернобыльской АЭС

Демонстрационная исследовательская версия к 18 ноября 2026 года. Две **разные** исторические машины, модели не заменяют заводские чертежи и не имеют сертифицированных размеров.

| Модернизированная машина, 1987 | [Мобот-Ч-ХВ-2 · v20](https://step3dlab.github.io/vr_anapa/mobot-engineering-v20.html) |

| Прежняя версия, сохранена | [Архив v17](https://step3dlab.github.io/vr_anapa/mobot-engineering-v17.html) |

Документация: [паспорт демонстрации](mobot-demo-release-2026-11-18.json), [изменения геометрии](mobot-geometry-changes-2026-11-18.md), [аудит архивных источников](mobot-archive-audit-2026-11-18.md), [сценарий показа](mobot-demo-script-2026-11-18.md).

Проверки включают WebGL2 на настольном и эмулированном мобильном экране, управление механизмами, переход **latest → v20**, открытие фотографий и паспорта по прямым ссылкам, резерв без WebGL и побайтовую проверку опубликованных ресурсов. Фактические результаты каждого прогона следует сверять с GitHub Actions; физические телефоны, точные размеры, работа привода под нагрузкой и полные коллизии не подтверждены.
