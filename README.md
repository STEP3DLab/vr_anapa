Проверки включают WebGL2 на настольном и эмулированном мобильном экране, управление механизмами, переход **latest → v20**, открытие фотографий и паспорта по прямым ссылкам, резерв без WebGL и побайтовую проверку опубликованных ресурсов. Фактические результаты каждого прогона следует сверять с GitHub Actions; физические телефоны, точные размеры, работа привода под нагрузкой и полные коллизии не подтверждены.

### Дополнительный интерактивный режим

`mobot-compare.html` использует две независимые сцены с настоящими WebGL2-моделями, синхронным/раздельным вращением, выбором видимых узлов, позами, сменным оснащением для модели 1987 года и резервными кадрами. При выборе элемента в 3D открывается справка с указанием оснований A/B/C. Масштабы сравнения адаптивно подогнаны для осмотра: геометрическое совпадение и заводские размеры **не утверждаются**.

QA: `scripts/mobot-compare-qa.cjs` (настольный и эмулированный мобильный Chromium, синхронизация и резерв без WebGL). Фактические результаты следует проверять по последнему запуску [Mobot research WebGL QA](https://github.com/STEP3DLab/vr_anapa/actions/workflows/mobot-research-qa.yml).
