 ПЕРЕД ПОСЕЩЕНИЕМ

Добро пожаловать
в павильон.

Мышь / касаниеПотяните, чтобы оглядеться. На телефоне стрелки слева перемещают по залу. Выбирайте экспонаты в нижней панели или на карте.

КлавиатураWASD — движение, стрелки — поворот, 1–4 — экспонаты, 0 — общий вид, M — карта, Esc — закрыть окно / вестибюль.

Детальный осмотрНажмите «Рассмотреть» в карточке. Потяните модель для поворота, используйте колесо или жест двумя пальцами для приближения. Esc — обратно в зал.

Игра «Резонанс»Нажмите «Играть». Поймайте указатель в светлой зоне трижды на каждой станции. После активации четырёх станций запустите Атлас. Спокойный режим не требует точной реакции.

VR-контроллерыЛуч + курок по полу — телепортация; по экспонату — переход к нему. Правый стик — поворот шагами по 30°. Сжатие контроллера вызывает путеводитель перед вами. После скрытия его также можно открыть лучом через кнопку «Путеводитель» внизу поля зрения.

Архитектура и оформление

Авторский проект в эстетике советского ретрофутуризма. Плакаты в зале созданы специально для этой экспозиции. Первый экран — художественная концепция; интерактивная сцена создана отдельно. Игровые модели и музыка Atomic Heart не использованы.
