Мышь / касаниеПотяните, чтобы оглядеться. Нажмите на экспонат, чтобы открыть описание.

КлавиатураWASD — движение, стрелки — поворот, 1–4 — экспонаты, 0 — общий вид, Esc — вестибюль.

VR-контроллерыЛуч + курок по полу — телепортация; по экспонату — переход к нему. Правый стик — поворот шагами по 30°.
